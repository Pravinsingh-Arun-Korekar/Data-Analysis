# 📊 Rupali Mobile Shop Sales Analysis Project

## 📌 Introduction
This repository is dedicated to **data visualization and business insight analysis** for Rupali Mobile Shop. It combines **Excel, Python scripts, and dashboards** to deliver actionable insights into sales performance, customer demographics, and brand trends.
---
## 📈 Project Summary
- **Title**: Rupali Mobile Shop  
- **Dataset totals**:  
  - Units sold: **19,150**  
  - Transactions: **3,835 datapoints**  
- **Top Metrics**:  
  - Avg price per unit: **₹40,167.36**  
  - Avg revenue per transaction: **₹2,00,574.96**  
  - Avg customer age: **38.10 years**  
  - Avg customer rating: **3.69 / 5**

-- 
## 🔍 Analysis Coverage
- **Model-wise**: Performance comparison across mobile models  
- **City-wise**: Revenue and transaction insights by geography  
- **Month-wise**: Seasonal and monthly sales trends  
- **Customer insights**: Age, rating, and demographic breakdowns  
--
## 🌟 Key Highlights
- **Top Brands**: Apple, Samsung, Xiaomi, OnePlus, Vivo  
- **Model Leaders**: Galaxy Note 20, OnePlus Nord, iPhone SE  
- **City Insights**: Chennai and Rajkot show higher revenue per transaction  
- **Demographics**: Ludhiana and Bangalore skew older in customer age
